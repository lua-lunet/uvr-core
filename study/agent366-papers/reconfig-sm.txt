  186  Reconfiguration made easy (cont'd)

  187  In order to have a reconfigurable SM implementation, we
  188  introduce cfg, a component specifying the current
  189  configuration. (i.e. the configuration at cmd i is determined
  190  by the value of cfg in the state immediately following
  191  execution of command i − 1)
  192  We add a new cmd: rcfg(C), specifying a new configuration C

  193  Francesco Bongiovanni – INRIA Reconfiguring a State Machine

  194  The obvious way to define the SM is to let executing rcfg(C)
  195  in order to set cfg to C. This method is called R1.
  196  The problem with R1: it prevents concurrent processing of
  197  neq proposed cmds since the configuration used to execute
  198  instance + 1 of the consensus algorithm can be changed by
  199  executing command
  200  ⇒ the SM implementation cannot begin choosing cmd + 1
  201  untill cmd has been chosen

  218  Reconfiguration made easy (cont'd)

  219  To allow concurrent processing of cmds, we define a SM with
  220  an additional state such that executing rcfg(C ) as cmd
  221  number i causes cfg to change after executing command
  222  i + α − 1, for some positive integer α
  223  A reconfiguration command can thus take effect α cmds later,
  224  allowing concurrent processing of up to α cmds. This method
  225  is called Rα.
